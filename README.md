# Financial-Sales-Dashboard
Financial Sales Dashboard using Power BI
Financial Sales Dashboard – Power BI Project

1. Project Overview

This project focuses on analyzing financial sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profit, discounts, and units sold across different countries, products, and business segments.

2. Tools Used

- Microsoft Excel
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

3. Data Cleaning and Preprocessing

- Checked the dataset for data quality.
- Replaced "None" in the Discount Band column with "No Discount".
- Checked column quality.
- Corrected data types of columns.
- Removed unnecessary duplicate sheet usage.

4. Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Units Sold
- Total Discounts

5. Dashboard Visualizations

1. Sales by Country
2. Profit by Product
3. Sales by Segment
4. Monthly Sales Trend
5. Sales by Discount Band
6. Sales vs Profit by Country
7. Units Sold by Product

6. Interactive Features

- Country Slicer
- Segment Slicer
- Year Slicer
- Reset Dashboard Button
- Default View Bookmark

7. Project Objectives

- Analyze financial sales performance.
- Compare sales and profit across countries.
- Understand product-wise performance.
- Identify monthly sales trends.
- Analyze the impact of discounts on sales.

8. Conclusion

This Power BI dashboard provides an interactive and easy-to-understand view of financial sales data. It helps users explore business performance and make data-driven decisions.
